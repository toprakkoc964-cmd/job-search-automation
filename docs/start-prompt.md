# Portable first-chat prompt

Paste the prompt below into an assistant that does not automatically load the repository instructions. If it cannot read the checkout, attach `AGENTS.md` or paste its contents into the chat.

> Set up my job search using the Job Search Automation project. Read the repository's AGENTS.md or the copy attached to this chat and use it as the workflow.
>
> Start by asking only for information I have not supplied: target roles and seniority, target countries and work arrangements, where I would work from, relevant skills and experience, optional portfolio links and application email, freelance preferences, and my upfront application budget.
>
> When you have authorized local file access, save confirmed facts in the ignored profile/candidate.md and build the local search configuration. If you cannot access the checkout, return a candidate profile and search configuration I can save myself. If you cannot run shell commands, give me the collector command to run. If you cannot delegate research, process the scopes sequentially. State which steps were actually completed and keep application materials as drafts.
